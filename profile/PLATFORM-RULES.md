# 平台发布规范：视频号 + 小红书（v1 / 2026-11-05）

## 通用原则

- 一稿两平台前先"翻译"：小红书吃**图文+干货密度**，视频号吃**人声+场景+情绪**，不能直接搬运。
- 选题内核一致（来自 `USER-PROFILE.md` 栏目矩阵），呈现形式分平台适配。
- 发布后必须归档到 `content/published/<平台>/`，保持跨设备状态一致。

## 小红书

| 项 | 规范 |
|---|---|
| 形式 | 图文笔记为主（首图大字标题 + 内页干货），后期可尝试口播视频 |
| 标题 | ≤20 字，带具体数字/场景/反差，例："算完这笔账，我把门店 30 个'员工'换成了'合作者'" |
| 正文 | 300–600 字，段落短，emoji 克制使用，标签 5–8 个（#人力资源 #连锁企业 #灵活用工 #门店管理 等 + 1 个业态标签） |
| 首图 | 大字标题卡：一句话钩子 + 深色底白字或白底深字，不用花哨模板 |
| 人设 | 个人专家口吻，第一人称"我"，像同行给同行划重点 |
| 频率 | 每周 2–3 条 |
| 黄金时段 | 工作日 12:00–13:00 / 20:00–22:00 |
| 转化路径 | 正文不放联系方式，评论区置顶一句"门店用工账算不清的，可以评论区聊" |

## 视频号

| 项 | 规范 |
|---|---|
| 形式 | 真人出镜口播 60–90 秒，现场感（办公室/门店场景）优先于精致 |
| 结构 | 3 秒钩子（一句话反常识/数字）→ 40 秒讲透一件事 → 收束一句主张 |
| 口播稿 | 180–250 字，口语化，写完删掉 20% 书面词 |
| 字幕 | 必加；关键数字上屏 |
| 频率 | 每周 1–2 条（比小红书少、比小红书重） |
| 黄金时段 | 早 7:50–8:30 或晚 20:30–21:30 |
| 转化路径 | 视频引导"评论区/私信交流"，主页签名档收敛到私信 |

## 一题两译示例（内核：费率账）

- 小红书：《灵活用工 4% 和劳务外包 14%，差在哪？我用 78 个标书写清楚了》
- 视频号口播钩子："同样是招人，为什么有人花 4 个点，有人花 14 个点？今天用 78 份招投标文件给你讲明白。"
