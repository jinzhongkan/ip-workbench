# 用户档案与 IP 定位（v1 / 2026-11-05）

> 写任何内容前必读。此文件是所有平台内容的"人设单一事实来源"，有更新随时改这里。

## 我是谁

- **身份**：小砖块公司全国 KA 负责人，深耕"真零工" / 无风险弹性用工合规方案。
- **IP 人设**：个人行业专家——"专业为企业优化人资的行业专家"。弱化公司身份，不挂产品、不谈费率，以专业判断建立信任，被动引流。

## 核心主张（内容之魂）

1. **真零工的关键不是管住 C 端，而是让 C 端自由，证据链才站得住。**
2. 合规不是签对一份合同，而是把每天真实发生的事留下来（结算留痕、自由接拒、多雇主生态）。
3. 真假灵工的分水岭在事后：税务抽查、工伤事故、诉讼时 C 端怎么陈述。让 C 端真的自由，出事时他天然站在甲方这边。

## 目标受众

- **锚点**：多店连锁企业的 HR / 人资负责人（50–500 店规模）。锚的是"门店分散"这个结构特征，不是行业属性——凡是门店分散，就有人资管理刚需。
- **可切业态**（10 个）：茶饮烘焙快餐 / 便利店生鲜前置仓 / 商超 / 美业 / 健身 / 教培 / 汽修洗车 / 宠物 / 医药连锁 / 酒店民宿。
- **暂不进入**：娱乐场所、按摩足浴、医美。

## 内容纪律（红线）

- **跨业态措辞纪律**：不说"餐饮门店""餐饮老板"，说"门店""连锁品牌方"。跨业态讲数据不编造。
- **一题多译**：同一内核换业态现场名词，可复用为多条内容。
- **不硬广**：不推销、不放费率，亲切、与生活有链接，专业但说人话。
- 发布渠道线索收敛到私信/评论区互动，正文不放营销信息。
